# DE25-Nano MAC0 observation before storage

This diagnostic samples MAC0's clock, reset, firewall and stream-ID configuration from the CBL's initial EL3 SPL. Use the RX-only UART verifier to interpret the two complete register samples. A reported `tsn0-reset` means that the SPL observed an asserted MAC or ECC reset and skipped the MAC version read. A changing sample rejects the capture. The system-manager NoC idle word describes HPS bridges and supplies no MAC DMA-drain evidence. The result does not grant the native network driver DMA access.

The builder starts with the vendor carrier and the original CBL initial-trace producer at `d3ec4a3928eac87477b67d7c92d6e63c4a0d1bc7`. It retains the qualified clock/console initialization, startup object checks and unconditional OCRAM Park before DDR, SD, QSPI or BL31. Its additional MMIO operations are normal-value register reads from the Agilex 5 CS/R1 register map. MAC0's CSR interface uses L4 SP. Reading `MAC_Version` also requires stable clock sources and deasserted MAC0 and ECC resets. [Altera register map](https://docs.altera.com/v/u/resources/864455/agilex-5-cs-and-r1-suffix-opn-hps-register-map) · [XGMAC clocks](https://docs.altera.com/r/docs/814346/26.1.1/hard-processor-system-technical-reference-manual-agilex-5-socs/xgmac-clocks?contentId=ZVIw1NaUa2BuEkJDgdUxAA)

Build in a private checkout on a filesystem with at least 30 GiB free. Pass `build.py --trace-checkout <original-trace-checkout>` the vendor U-Boot checkout, cold serial seed, matching entry, compiler, vendor SOF, Quartus PFG and fresh output arguments from the historical producer. The output must be under the historical checkout's `out/`. The builder checks the emitted OCRAM bytes inside the candidate SOF and compares the unchanged vendor FPGA sections. The resulting `mac-observation.json` identifies the candidate, its UART ID and the exact parser. [Qualified original trace](../../../../docs/validation/2026-11-01-de25-initial-trace/README.md)

On an assigned CBL, the diagnostic uses the volatile JTAG SOF operation and the board's if02 receive-only UART. The operator arms UART before dispatch, checks the original SPL build banner and 18 checkpoints, replays both register samples through `verify.verify(raw, diagnostic_id)` and requires the final hardware Park. Restore the baseline named in the current CBL ledger using its qualified volatile procedure and verify its boot and Park before releasing the claim.
