# DE25-Nano MAC0 observation before storage

This diagnostic samples MAC0's clock, reset, firewall and stream-ID configuration from the CBL's initial EL3 SPL. Use the RX-only UART verifier to interpret the two complete register samples. A reported `tsn0-reset` means that the SPL observed an asserted MAC or ECC reset and skipped the MAC version read. A changing sample rejects the capture. The system-manager NoC idle word describes HPS bridges and supplies no MAC DMA-drain evidence. The result does not grant the native network driver DMA access.

The builder starts with the vendor carrier and the original CBL initial-trace producer at `d3ec4a3928eac87477b67d7c92d6e63c4a0d1bc7`. It retains the qualified clock/console initialization, startup object checks and unconditional OCRAM Park before DDR, SD, QSPI or BL31. Its additional MMIO operations are normal-value register reads from the Agilex 5 CS/R1 register map. MAC0's CSR interface uses L4 SP. Reading `MAC_Version` also requires stable clock sources and deasserted MAC0 and ECC resets. Build in a private checkout on a filesystem with at least 30 GiB free. Pass `build.py --trace-checkout <original-trace-checkout>` the vendor U-Boot checkout, cold serial seed, matching entry, compiler, vendor SOF, Quartus PFG and fresh output arguments from the historical producer. The output must be under the historical checkout's `out/`. The builder checks the emitted OCRAM bytes inside the candidate SOF and compares the unchanged vendor FPGA sections. The resulting `mac-observation.json` identifies the candidate, its UART ID and the exact parser. [Qualified original trace](../../../../docs/validation/2026-11-01-de25-initial-trace/README.md)

On an assigned CBL, the diagnostic uses the volatile JTAG SOF operation and the board's if02 receive-only UART. The operator arms UART before dispatch, checks the original SPL build banner and 18 checkpoints, replays both register samples through `verify.verify(raw, diagnostic_id)` and requires the final hardware Park. Restore the baseline named in the current CBL ledger using its qualified volatile procedure and verify its boot and Park before releasing the claim.

## MAC0 after DDR calibration

`build_admission.py` packages a separate volatile SPL from the [CBL-qualified v2 CPU parking source](../../../../docs/validation/2026-11-01-de25-initial-parking-v2/README.md). Supply its checkout at `87b2d7f4721c819b554212f2b80c193a07a2531e` with `--trace-checkout`, its matched cold seed and entry, and the historical producer's vendor U-Boot, cross-compiler, SOF, PFG and fresh output arguments. The SPL executes the stock security and DDR initialization, reports two eligibility samples, then Parks before storage or BL31. The build checks the linked symbols and compares every embedded SPL byte with the ARM build. It excludes the transmitter, SMMU configuration routines, frame and descriptor writer.

The samples report the boot CPU and power ownership, primary RAM bank and global RAM size, L4 and EMAC clock sources and rates, TSN0 reset and stream routing, and the nonsecure and secure SMMU controls. The SDM `CONFIG_STATUS` query uses the vendor mailbox, which writes a status request to the mailbox FIFO and consumes its reply. Each pass records the transport result, returned length and six response words alongside the vendor's interpretation. A successful transport can report a fabric that has reached `CONF_DONE` but still lacks `INIT_DONE`. An unavailable supplier or moving configuration remains visible in the report. [CBL phase-one SDM evidence](../../../../docs/validation/2026-11-01-de25-fpga-ready/README.md)

`verify_admission.decode_admission(raw, receipt)` replays the 32 initial and terminal CPU checkpoints, both register samples and Park. `held` requires a stable reset-held MAC/ECC, the original stream route, idle disabled SMMU controls and verified CPU ownership. `eligible` additionally evaluates the prerequisites used by the transmitter. An observed CSR clock from 100 MHz up to 150 MHz uses the existing MDIO divider of 62. Higher documented clock ranges use different divider settings. The report reproduces the original TX04 startup predicates, including its 125 MHz parent assumption and its requirement that the SPL already masked SError. The later transmitter establishes its own exception mask and uses the documented parent clock. ## Single-frame TX diagnostic

`build_positive.py` uses the same v2 boot inputs and takes `--frame` and `--frame-sha256`. The 60-byte private frame includes the witness's unicast destination, the assigned CBL source, EtherType `0x88b5`, `FES-CBL-TX-v1` followed by NUL, a 16-byte per-run nonce and 16 zero pad bytes. The destination and nonce are part of the complete digest supplied to the producer. Use a fresh witness and capture on the assigned receiver to qualify transmission.

The fitted design selects EMACA as the EMAC0 reference and routes RGMII with MDIO through the dedicated HPS pins. The SPL checks the EMAC0 selector, PLL lock, counter gates, bypass and reset, and uses the vendor clock provider to verify the 250 MHz controller reference and 100 MHz CSR clock. While the MAC and ECC are in reset it selects RGMII (1). It reads back TX_CONFIG.SS=011 before enabling TX. At 1 Gb/s Altera specifies that the hard MAC divides the reference by two to supply the 125 MHz RGMII TX clock. This is a derived clock rate. Clause 22 checks the PHY identity, both link partners’ advertisements, and the final 1000BASE-T full-duplex status reported in PHY register 31. [Microchip KSZ9031RNX Table 4-4](https://ww1.microchip.com/downloads/aemDocuments/documents/UNG/ProductDocuments/DataSheets/KSZ9031RNX-Data-Sheet-DS00002117.pdf). [Altera XGMAC clocks](https://docs.altera.com/r/docs/814346/26.1.1/hard-processor-system-technical-reference-manual-agilex-5-socs/xgmac-clocks) and [EMAC HPS initialization](https://docs.altera.com/r/docs/814346/26.1.1/hard-processor-system-technical-reference-manual-agilex-5-socs/emac-hps-interface-initialization)

After the startup suppliers pass, the verified EL3 primary checks that debug, IRQ and FIQ are masked and that ISR_EL1.A is clear. It sets PSTATE.A with `MSR DAIFSet,#4`, reads back all four masks, and checks the pending SError bit during the trial. The terminal SPL retains these local masks through Park. [Arm exception model](https://developer.arm.com/documentation/102412/latest)

The standalone SPL keeps MAC0 in reset while it creates a default-abort stream table and a two-page nonidentity stage-2 mapping for SID 1. One mapped page holds the descriptors, and the second permits only reads of the frame. The physical backing at the two IOVA values is checked empty. The SPL checks its CPU, stream, translation-table and queue ownership at each DMA boundary. A completed TX requires descriptor completion, a fresh process-stopped acknowledgement, an idle MAC queue, acknowledged translation revocation, matching reset readback and Park. `verify_positive.decode_positive(raw, receipt)` replays the target half. The receiver must independently observe the entire matching frame. `decode_closed` also recognizes a proven, untouched refusal or a revoked mapping before any DMA became possible. Uncertain domain state requires the recovery procedure for that board.
