# FES structure

First-party sources share this repository. Module ownership stays separate.
Feature work that crosses modules uses one FES worktree and one PR.

The ownership decision is [component boundaries](component-boundaries.md).
The directory map is the [project map](project-map.md). The package matrix is
[core status](core-status.md). Current commands are the
[development guide](development.md).

The old merge diary, cutover checklist and migration investigation that used
to live beside this page have been removed. Git history still has them.
They are not instructions for the tree you have open.
