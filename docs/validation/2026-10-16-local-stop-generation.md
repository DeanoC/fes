# Generation-bound local Stop diagnostic

On 2026-10-16, kit A (`192.168.10.84`, target `73dc9f5f-1a12-4a95-a820-a9b4e600769a`) passed the local-control API diagnostic. Two sequential launches of the same installed FES Pong package returned distinct execution generations. Empty-body Stop and a valid but wrong generation returned 409 while the first run remained current. After stopping that run and launching the same package again, its old generation returned 409 and the second run still reported running with its own generation. Each current-generation Stop returned 200, ending idle with a free lease.

This is a hardware diagnostic using the agent's root-only local socket through SSH. Local launches acquired the target-enforced local-core execution lease; no direct runtime programming, foreign lease takeover, physical controller input or host library edits occurred. The immediate HDMI sample was black and supplies no visible-game acceptance evidence. Physical controller acceptance from the earlier bundle does not qualify this new artifact.

The combined dependent stack was built from source `1b715ad57f68133536bbe960d17b30234e18887b`, containing Stop implementation `6d0dfb0c6b1c128f8d501cad49f13602d021c48d` plus the initial Installed cores default. Its active/selected bundle was `e1d724c154f1936445e2b985cbe8498be9002b898e1b6f4b025c2e3c5025cb93`, software generation 13. This is not exact-PR-head appliance-image acceptance. The new default's unavailable-room startup failure was discovered separately and is being corrected in its dependent PR.

The leased software API diagnostic installed while held, rejected a competing claim, verified request idempotence/conflicts and explicit cancellation, retained the queue after its requesting process exited, and accepted activation after release. Supported core inventory/selections were unchanged. The successful selection remained installed. Boot ID `14c05a47-1615-43f0-a084-a1dc8948c119` and base image `ed721b84074b039daf66bad2aa24276b88dd8cd713b5cfcdb2c2f25489be4ad2` remained unchanged; no reboot occurred. The bundle's base contract matched the base image; source commit equality was not required.

Host validation includes the full localcores race suite, tenfoot/rooms suites, kitlauncher suite and focused transition race tests, agent cleanup integration, independent concurrency review, `make check`, and ARM bundle builds. The first affected-check run encountered two unchanged maintenance-journal fixture failures under ambient umask 0002. Both pass under umask 022, which is used for the affected-check rerun. No production workaround was added for that test environment.
