# 286 wide instruction-loop diagnostic, 16 November 2026

This reference survey was fixed and reported before the 86Box results. Fourteen 1,000-iteration loops exercise odd-address word memory operations, CL shifts, multiply/divide, PUSHA/POPA, flag stack, XLAT and LEA; all timed loop bodies have identical assembled bytes between RTL and reference. The reference configured 86Box 6.0 as a 12.5 MHz 286 with one wait state; the RTL binary used diagnostic enabled, SHA-256 `9beadd324d3a965987f1563a4a67f5e1c59ab6cba7ca0026c0e1e67506ee5b06` and `candidate-manifest.json` describes its locked source and tools. Checked reference COM SHA-256 `88c789f7207e7be6ef0d869983993cd6c5c7399580f071b956ed121873d7a384`, RTL binary SHA-256 `e9430bfdab2bcad35123817c4df25d5486578c33fcd0d849bd5133757d0302f0`, and fixed `rtl.json` predictions SHA-256 `27f6e2d8da0b246834777317ed3512a92ca914e934913754bf41f24ee6576cfa`.

The three identical result files came from one private 3090 emulator boot and include an odd-word write/read and neighbor-canary control; output SHA-256 `c72906009701a72624a6033a609e50ff0e2a7aa19837197eb5b3a1f9f87f9e8a`. Captured screenshots display 100% speed only at capture instants; there is no continuous speed trace. Estimates in `comparison.json` are whole-loop clocks including BIOS timer, interrupt and block setup; RTL uses a distinct marker harness. One-block quantization does not bound all systematic error, and tests do not measure individual instructions in isolation.

The 286 reference estimates differed from frozen RTL by at most 0.032 clocks on six odd RAM loops, PUSHF/POPF and XLAT. Material mismatches remained: memory SHL by CL=3 about 4.98 clocks too high, byte memory MUL and DIV about 2.98–2.99 high, PUSHA/POPA about 5.99 low, and complex LEA about 1.98 high. These are failures of this sampled reference comparison and are not waived. A separate altered-encoding holdout is retained in `../forms-holdout/`; it is not a basis to mark this initial matrix as passing. This experiment supplies no exact-artifact pitch, timing, seal or hardware acceptance.
