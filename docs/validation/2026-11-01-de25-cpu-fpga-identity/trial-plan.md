# One bounded secure CPU identity attempt

Use only TRWU8CBL under its continuing exclusive claim. Keep the spare card
inserted and original factory card safe. Require all exact planned software
commands, source checks, actual sealed-package simulation and helper fixtures
before any device access. Verify the current USB serial/node and UART ownership.

Load the unchanged qualified recovery SOF through the exact top cable at 6 MHz.
Download the matched native FIT over Ethernet, overwrite only FES/UPLOAD.BIN,
independently read it back, and verify the protected boot files and manifest.
Then load the matched whole-SOF native candidate, verify the source-bound SPL,
manual U-Boot and closed ownership, and issue exactly one fesboot.

Require source-context readback followed by open/read/close/closed trace masks
f/d/d/f and generations1/2/2/3, and the exact FPGA ABI/build and CPU aperture.
Firmware performs no endpoint writes; all data bridges and masters stay held.

An error returned by the control operation triggers independent control reset
and permanent retirement. A synchronous CPU abort or a hung MMIO/SMC may prevent
that callback from running. The host stops after the bounded observation window,
retains the first trace and does not retry or infer a successful reclose. JTAG
recovery is a separate action after evaluating that stopped state.

Always restore/read back the original 15 MHz cable clock, restore exact USB
permissions and close the UART. Retain the diagnostic/spare/claim under user
policy; no factory restore is required. A successful identity read does not
qualify live HPS I/O measurement, active fabric/master drain, SDM programming,
native SD coexistence, HDMI, USB/network resume or runtime core admission.
