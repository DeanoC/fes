`b3ed4389ad43d91b`, after the successful physical first installation. Its prior
three-file capture is hash-bound and replays the actual first-install wire.

bootstrap. There is no network uploader, staged SD-write command or native Install
command in this controller. The native boot must discover ZX81 from the owned
installed store, then launch, return to the menu and reach final Park.

wrong-digest/lost-ownership negatives. Transport, reader/operator, epoch and
programming-gate models pass; the actual successful prior capture also passes.

is not predeclared. Results will be recorded after the bounded experiment.
