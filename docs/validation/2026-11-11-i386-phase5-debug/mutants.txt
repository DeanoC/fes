i386 Phase 5 slice 5 (breakpoints and single step): one-line mutants of the new RTL
==================================================================================

Each mutant changes one line (or one expression) of fes_i386_cpu.sv or
fes_i386_ex.sv, builds the lockstep testbench (the lock's Verilator 5.054)
and runs the pmode directed cases and 60 debug programs of seed 5001
against Bochs. "pmode" counts the directed cases that fail, named after it;
"debug" the debug programs that fail. Mutants run first on the testbench of
92d08101b; those whose first run failed no directed case were run again
(marked "rerun") on 68a1eb3d2's, with the cases added for them. 68a1eb3d2
matches a descriptor's access with a data breakpoint, so "system-matches"
(the first run) became "system-ignored" (the rerun's opposite mutant).
