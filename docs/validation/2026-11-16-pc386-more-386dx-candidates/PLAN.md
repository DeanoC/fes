# Additional 386DX-25 board screening

Before this screen, choose only the 86Box 6.0 `asus3863364k` board, selected because its 386DX package admits 25 MHz and its named 64 KiB cache makes it a candidate for the already committed cache criterion. Freeze 86Box executable, ROM tree, a private benchmark disk copy, config and CMOS before a timing run. Use the existing scaled real 386DX-25 TopBench distribution: lower quartile 47, median 57, upper quartile 65. A score below 47 rejects this specific setup; a score within the band is only a candidate pending verified cache state and Ultima VII disk/map/start compatibility. Do not change clock, CPU type, or this band after results. Capture all speed samples through the measurement, verify guest benchmark output and machine identity, report invalid if speed or setup cannot be proven. A preparatory blank-CMOS boot is only setup discovery and not a timing result.
