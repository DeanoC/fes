# Additional 386DX-25 candidate screen, second batch

Before running this batch, select `micronics386px` (Micronics 09-00021, Phoenix BIOS) and `ecs386` (ECS 386/32, C&T chipset). Both 86Box 6.0 machine entries accept 386DX at 25 MHz with ISA. Their effective external-cache state is unverified; an in-band score would require cache verification and a successful Ultima VII map/start gate before selection. Both are exploratory unless BIOS configuration, guest score and speed checks support a valid measured configuration. Fix the same pre-existing selection rule and scale as PLAN.md (IQR 47–65, median 57) and freeze emulator, ROMs, config, CMOS and benchmark disk before any measured run. A below-band score rejects only the measured configuration. Missing ROM, incompatible BIOS or setup and failed speed controls yield inconclusive, not rejection.
