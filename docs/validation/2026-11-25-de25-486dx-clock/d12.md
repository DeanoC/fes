# D12 for the other DE25 packages

D12 compares main at `da4acd2ac3213e467dcd98f0bbf26a2158b70a3e` with the
selected DX candidate. It covers MENU, ZX81, Spectrum 48 and 128, Atari ST,
C64 PAL and PC/XT XT. The C0 = 34 candidate `3df878912` has the same captured
input files, parameters and selection identities as main for all seven.
The [selection report](d12-c34-selection.txt) comes from both revisions'
ordinary record creators with the selection-only flag.

With equal design BUILD_IDs, the ordinary build on each revision supplies
the two RBFs to compare directly. A takes the compile-only route from main.
B takes the normal producer route from the selected candidate. Each fit
takes a separate Quartus Pro lease. The comparison checks the two complete
functional records, project inputs after absolute path substitution, RBF
bytes, and B's admission and manifest. D12 requires all of those checks for
all seven packages.

Run from the FES worktree, using the output directory created for this issue.

```sh
record=docs/validation/2026-11-25-de25-486dx-clock
out=/data/projects/de25-486dx-clock-2263/d12
base=$(git rev-parse da4acd2ac)
candidate=$(git rev-parse HEAD)
bash "$record/d12.sh" A "$base" "$out"
bash "$record/d12.sh" B "$candidate" "$out"
python3 -I "$record/d12_compare.py" compare \
  "$out/source-A-$base/sources/misteross/build/d12" \
  "$out/source-B-$candidate/sources/misteross/build/d12"
```
