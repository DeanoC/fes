# Bounded installer observer for two cores and a prior library

Against `ec70fb277`, the host observer now takes an explicit list of staged
programs, installed-state mask and independently expected initial library titles.
It selects each presented source by its frozen ordinal, installs each uninstalled
entry, opens the library, focuses the exact unambiguous target and verifies every
launch/return before final Park. A prior library need not be empty. Existing
per-operation limits remain unchanged; observed native counters are never
rewritten. Each install uses its actual current generation as local decoder
context and advances the completed-install origin once after complete proof.

The shared focus engine verifies one bounded arrow move at a time, including
movement past unrelated titles, without configuring devices. Unchanged installer
panels may reuse their cached owner/generation during focus; a fresh matching App
state and presented menu frame are still required. Library refresh may retain
its known previous view before complete publication. Sorted publication uses
the last observed, verified title order during the next install. Ambiguous target
titles reject before keys; this diagnostic limitation does not change product
handling of game IDs. Fresh hardware staging labels are therefore ZX81 trial
and ZX80 trial, preserving the previously installed ZX81 label and entry.

Read-only recovery now requires an explicitly selected fixed ten- or fourteen-role
sequence. It cannot infer a smaller set from supplied payloads, adopt an upload
ledger, start a server or write the card. Alternate-file mismatch stops before
later roles and closes the session. These source checks do not prove persistence
or the content of installed records.

Seven target/failure model cases plus the ordering regression cover two installs,
a separate no-reinstall discovery cycle, the existing library, UART-only and
shared USB operation, second-install owner/resume/master/generation failures,
wrong second activation, invalid selections, open controls and failed focus.
Failure retires the observer before another command. Synthetic captures built
from retained C/menu fixtures replay all commands and polling offers. Two
unmodified saved physical single-core captures also replay through the updated
observer with explicit context. Neither replay is a new hardware test.

The broad parent run passed 1,945 tests with three skips. A final library-ordering
correction was then covered by 84 focused installer/paired/trace tests, the
synthetic replays and both historical captures. The broad run's cached imports
precede that last two-line correction; it is not reported as an exact-current-
source exhaustive run. Planner, whitespace and generated-consumer checks pass.
All selected target SDK, entry, firmware, U-Boot and composition hashes remain
unchanged. The existing matched target boot ID is fc2cec132701a0d8; this host-only
change does not rebuild or qualify it on hardware.
