# Private prospective 286 CMP survey

The generator derives byte-matched DOS and FES guest loops for 38/39 memory-destination CMP and 3A/3B register-destination CMP. Each form exercises byte/word width, register-indirect/indexed/displaced/direct addressing, redundant DS or ES segment override, and alternate DEC/JNZ and LOOP scaffolds. The unequal cases separately exercise borrow and non-borrow behavior; the others compare equal operands. `instruction-identity.json` records the isolated instruction and the complete timed loop, plus the actual offsets in both guests. The program checks the captured arithmetic flags, both operand words and register operands, loop counts, canary, SP and segment values. The result marker indicates all controls passed; failures are retained and do not become timing evidence.

Every timed loop includes `PUSHF/POP DI` and its loop scaffold, not just CMP. DOS output counts 1,000-iteration blocks over 64 BIOS ticks. FES charged clocks include marker/setup overhead. Any reference comparison is a whole-loop estimate, with tick quantization and ISR/block/setup and differing marker overhead as additional uncertainties. One reference boot and one CPU prediction cannot establish broad accuracy. Prefix effects and queue phase are part of the measurement; they cannot be subtracted as an assumed constant. Guest reference timing and this diagnostic model do not establish physical 286 behavior.

`commands-frozen.jsonl` is a proposed three-run reference command sequence; each run gets 90 seconds for 20 measurements. Before use, independently confirm these result filenames are absent from a new private disk, record pre-run read-only disk and ROM/emulator/config identities, verify the exact absolute disk target before each write using the parent-approved guard, verify COM readback, preserve the complete 4 fps speed indicator trace and classify any sub-100% or unreadable frame as inconclusive. This directory does not itself run or modify a reference VM.

## Required non-RAM fallback controls for any candidate

Independently test both 38 and 39 against the *preceding diagnostic*, not production, at the governor boundary: wholly ordinary RAM; pure VGA MMIO; word crossing RAM/MMIO and crossing unknown/non-RAM; instruction-wide mixed-uop RAM then non-RAM and non-RAM then RAM; adjacent boundaries; abandoned/replayed instruction; reset/turbo/max; and every non-286 preset. Preserve the prior diagnostic execution, refill and accumulated memory wait charges and queue evolution for every excluded case. Include non-RAM 3A/3B controls and operand/address-size or prefix forms outside any measured predicate. Verify ordinary-RAM classification reaches the same retirement with independent whole-CPU address-range checks; a module-only synthetic predicate is insufficient to prove CPU wiring. Avoid physical MMIO device writes and do not claim device conformance. No candidate or fallback behavior is implemented here.
