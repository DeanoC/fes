# Native parent build

Implement the first slice approved in chat: a thin parent repository with pinned FogCast and libmister-runtime submodules. Build the Linux amd64 FogCast host and the existing native-dev image, preserving the child image recipe and locked upstream RBF inputs. Pin the exact hardware-baseline sources cd85971bf0bffe36e69c381917f618620b901726 and 443b603de991b56b5f4d0d11c5bc88a3f83fad13. No child source edits, automatic deployment, new FPGA build lane, or legacy assembly in this slice.

The parent checks submodule identity and cleanliness and checks the runtime pin against FogCast's lock. It publishes outputs to out/native-dev, records hashes and inputs, and reuses only outputs whose hashes and input fingerprint still match. Image construction remains the existing independent two-pass build. Explicit verify reruns structural checks and QEMU packaging smoke. A private Docker output volume per workspace isolates builds from existing work.

Component builds use clean standalone clones derived from the submodules so Git stamping and container source verification see the component's own identity. Historical image comparison is informational: the accepted image embeds agent revision 19a3d5e despite its acceptance record naming cd85971.
