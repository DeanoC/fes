# Specifications and plans

Older POC files in `specs/` and `plans/` preserve historical reasoning,
execution records, and evidence for their stated scope unless a current
authority explicitly adopts them. They are not current architecture or an
active migration plan merely because they remain in these directories.

The [approved portable target runtime design](specs/2026-08-08-fogcast-portable-target-runtime-design.md)
is current supporting detail, subordinate to the
[canonical architecture](../ARCHITECTURE.md), accepted
[ADR 0001](../adr/0001-portable-target-runtime.md) and
[ADR 0002](../adr/0002-disposable-local-development-target.md), and the
[active migration roadmap](../ROADMAP.md). Do not execute an old checklist
unless a current approved plan explicitly adopts it after confirming scope,
authority, dependencies, safety, evidence, and migration gates.
