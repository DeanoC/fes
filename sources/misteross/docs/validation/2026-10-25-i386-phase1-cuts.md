# i386 Phase 1 cuts: L stage, Q select, D forwarding and AG, re-measured

Dated record, 2026-10-25. Host simulation and routed diagnostics on Powerboat.
No package, RBF or kit. It implements the pipeline the
[i386 CPU design](../i386-cpu-design.md) adopted after the
[first spikes](2026-10-25-i386-phase1-spikes.md) (DeanoC/fes#1081) and
re-measures it under rule 9. Run data:
[`2026-10-25-i386-phase1-cuts.jsonl`](2026-10-25-i386-phase1-cuts.jsonl), one
line per route with argv, tools, GPU, fmax, per-stage figures, utilization
and critical path.

## What was built

- **F2** registers the L1I's way-selected block; nothing decodes M10K data
  in F2 (rule 7).
- **L** runs the 16 per-byte length decoders on that register. For each of
  the prefix accumulator's four 66h/67h variants it stores, per byte, the
  length, where the instruction ends and whether it ends in the next half.
  CS.D and the byte's own prefix are folded in, since a CS.D change flushes.
- **Q's loop** picks the stored end by the accumulator's two flags and then by
  start. It is a select with no add. The prefix rule is unchanged.
- **D** decodes the address registers from ModRM and SIB. It reads the
  flip-flop register file, forwards from the M1, M2, EX and WB result
  registers by comparing destination tags, and scales the index.
- **The late operand.** One value per uop may still be late: the previous
  uop's early-ALU result (in M1), M2 load data (in EX) or an EX late-ALU
  result (in WB). It enters AG's last 3:2 row as a base or an unscaled index.
  D stalls a late scaled index, two late operands, or a value further off.
- **AG** keeps a 3:2 row from registers, the last row with the late operand,
  one carry chain per sum and one select. The 16-bit wrap's high half comes
  from bits 17:16 of the two sums.

One prefix-free instruction issues per cycle, and an instruction with k

The D and AG cases split as follows:
- 1,103,253 produced an address, 310,563 of them with a 16-bit wrap.
- Of those, 402,243 operands were forwarded from a result register and
  693,575 came from the register file.
- 145,494 had a late base: 65,640 from M1, 43,957 from EX and 35,897 from WB.
- 60,548 had a late unscaled index: 27,838, 18,101 and 14,609 from the same
  three registers.
- The rest stalled: 456,625 because a value was further off, 6,850 because
  both operands were late, and 6,136 because the late value was a scaled
  index.

Two mutations show the check bites:
- dropping the late-scaled-index stall gives 6,136 failures;
- swapping the 16-bit-wrap high halves gives 526,628.

**Yosys finding.** Running the checks on Yosys's netlist first showed 10.6
million length mismatches per default size. Yosys 3a5accbd reads a
struct-returning function called from another function as empty, and the
decoder's `form()` helper was one. The fix is in DeanoC/fes#1080 and its note
records that its routes used the smaller, mis-read decoder. Two more Yosys
facts:
- without `proc -norom` it turns the 0Fh opcode table into an asynchronous
  ROM, which nextpnr rejects as an unclocked M10K;
- it silently mis-sizes packed arrays of structs.

The RTL README lists the rules.

## Timing spikes

`scripts/benchmark_fes_i386.py`, seeds 1-4, HIP on Powerboat through
`gpu-run` with `NEXTPNR_REQUIRE_GPU=1`. Synthesis is `proc -norom;
synth_intel_alm -family cyclonev -nolutram`. Every route logged a live HIP
backend. GPUs were shared FIFO with another owner's routes during some runs;
that changes route time, not results.

The spikes:

- **Front end:** F1; F2 behind a 16 KiB 4-way L1I model (M10K tags and data,
  four compares against a registered ITLB page, way select); L; the buffer;
  Q.
- **D+AG:** addressing decode, register file, forwarding by tag, scaling and
  segment select in D, then AG.
- **M2:** unchanged; it is the control.

slack among the registers the stage writes, from nextpnr's per-endpoint
timing, as the clock that stage alone would allow. The corrected model
(nextpnr `bd7a1c0d`, the newest authenticated lock) is the design figure, as
the design's compiler row says.

### Against rules 7 and 8

- **Rule 7.** F2 now has only compares and a way select behind the M10K,
  M2's shape, and routes at 72-79 MHz against M2's 102-106. Its way select is
  128 bits where M2's is 64, and its register feeds L's 17 decoder units, so
  the shape alone did not carry M2's clock to F2. L, which now holds the
  decode, is the slowest stage. Its 10-12 LUT levels are well over the
  design's "about seven". Folding each byte's position into the decoders'
  sums did not change that: the first L, which added the position after
  decoding, routed at 61.6-63.6 MHz (corrected model), and the folded one at
  61.4-67.5. The depth is the decode itself: prefix and escape detection, the
  opcode tables, the ModRM and SIB bytes, the immediate size and their sum.
- **Rule 8.** AG keeps two LUT levels before its chain and one after it. The
  late-operand select runs beside the first 3:2 row, then the last row, and
  after the 32-bit chain only the address-size select; the 16-bit wrap's
  carry compare follows bits 17:16, which the chain reaches 14 stages
  earlier. AG routes at 96-102 MHz
  (two seeds above 100), against 77-81 MHz for the first AG. The cut moved
  the forwarding mux into D, which is now the slower of the two at 79-85 MHz.
  D has no carry chain, but nine to eleven LUT levels.

### Where the clock lands

Every stage of the front end misses 100 MHz under the corrected model, and so
does D:
- **L is slowest**, at 61-68 MHz. These routes show 1.2-1.5 ns per LUT level,
  logic and routing together. At that rate the design's "about seven LUT
  levels", plus clock-to-out and setup, comes to about 85-105 MHz; the decode
  as built is 10-12 levels.
- **Q's loop** is next, at 65-71 MHz. Even with no add, it is by estimate
  about seven levels: the in-buffer check, the variant select, the 32:1
  select, the issue decision and the register enable. Its path is not traced
  here.

Under rule 9 the clock therefore lands at the measured figure: about 61-67 MHz
for these stages as built.

Options the measurements point at, for a later decision. None is made here:
- **L in two stages:** lengths, then ends and next-half bits.
- **Q:** store per-position availability so the loop's check is a register,
  and duplicate start for fanout.
- **D:** compute the forwarding selects a cycle earlier from the tags of the
  uops then one stage younger, so D keeps a registered select and the
  scaling.
- **F2:** replicate the hit signals across the 128-bit way select.
