## The 386EX's BOUND

Before any RTL, rules were fitted to the corpus's four files (`62`, `6662`,
`6762`, `676662`) and checked on all 10,000 states; every one matches.

| Case | The 386EX |
| --- | --- |
| The bounds | The lower at the operand's offset, the upper past it by the operand size, that offset wrapped by address size (`62#1725`: lower at FFFEh, upper at 0) |
| Limits | Each bound checks its own limit: #GP(0), or #SS(0) for SS |
| Order | Both bounds read, and check their limits, before either compare: 12 states have the register outside the bounds and only the upper past the limit, and all 12 raise #GP(0) or #SS(0) |
| #BR | When the register is below the lower bound or above the upper, signed, at the operand size; the frame's IP is BOUND's own |
| Flags and registers | Unchanged, in the 4,592 states that complete and in the FLAGS image each of the 1,846 #BR frames pushes |
| A register operand, LOCK | #UD |

Bochs agrees with the corpus on all of it but two general rules the Phase 0
divergence list already has: a real-mode delivery reads its vector before
it pushes (`interrupt-vector-before-push`, whose deciding case is
`62#1752`), and an invalid SIB scales its base (`invalid-sib-scales-base`).
The lockstep's corpus run below compares every retirement of the four files
with Bochs under those two entries.

## How it runs

- **DC** decodes the load of the upper bound into T1 (a far pointer's
  selector address, `sel_part`, past the offset by the operand size and
  wrapped by address size), with the register carried in src1.
- **The ROM** loads the lower bound and compares the register with it, then
  compares T1 with the register, which waits in D until T1's load retires.
  Each compare is a CMP that writes no flag and raises #BR (`FAULT_BR`)
  when its first operand is below its second, signed.
- **EX** raises it from the adder: the carry out at the operand size, which
  is not a borrow, differs from the top bits' propagate, as the SF and OF a
  CMP would write differ. It sets the uop's fault after `taken`'s select,
  so no branch path sees the adder; WB delivers #BR as any fault, pushing
  BOUND's IP.
- **The microcode words** gain three fields: `rg`, a source that is the
  instruction's register (carried in the first uop's src1), `rm`, a memory
  operand that is the instruction's ModRM operand, and `bound`. The ROM
  grows from 25 to 27 words and from 64 to 67 bits.

## The testbench

- `SCOPE` gains `62`, so the corpus run takes its four files (10,000
  states).
- Random programs gain a BOUND block: a MOV sets the register and two MOVs
  store bounds at a direct offset, mostly around the register's value, at
  an edge now and then (a quarter of each bound's spreads are 0), and
  outside them in one block in twelve; now and then the register's MOV
  comes last, so the compares take it forwarded, and one BOUND in 64 has a
  register operand.
- **A generator fix.** The first full run had one failing program (seed
  15, program 1716): a backward jump landed on an indirect far JMP after
  the code it had skipped moved DS, so the jump reread its pointer from
  elsewhere and the program ran into memory that was not its code, up to
  an `FF /7` that the RTL does not build. The far jump block now fences, as
  the other blocks whose rerun would go wrong do (`e8ffaf5721`).

## What the design doc should say

This is reported for the doc's owner to write; the doc is unchanged here.

- **BOUND** reads both bounds, each checked against the limit, the upper's
  offset wrapped by address size, before either compare, as the 386EX
  does; #BR is a fault (BOUND's own CS:IP pushed).
- **Microcode words** can address the instruction's ModRM operand and name
  its register, which BOUND needs and the routines before it did not.
