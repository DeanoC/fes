# ZX81 room artwork

`zx81.png` is an original generated illustration produced for FES with OpenAI
ImageGen on 27 September 2026. It depicts the ZX81 base computer as a visual
aid, not a documented board/model revision or evidence of compatible hardware.
The prompt requested a black wedge, membrane keyboard and empty space around
the base machine, with no fitted expansion. Keyboard legends and connector
details are illustrative. It contains no third-party photograph. It is
distributed with this repository under its licence.

The room labels the rear expansion position separately and uses host-owned
package validation for every choice. Cards use generic drawn silhouettes
until attributed per-card artwork is available. Missing machine artwork has
a labelled drawn fallback; all controls remain available.
